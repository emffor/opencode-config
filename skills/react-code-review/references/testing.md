# Testes React

## Cobertura

- Verificar mudança de comportamento sem teste.
- Verificar bugfix sem teste de regressão.
- Verificar fluxos críticos.
- Verificar autenticação e permissões.
- Verificar validação.
- Verificar contratos de API.
- Verificar estados loading, error e empty.

## Qualidade Dos Testes

- Verificar assertions frágeis.
- Verificar mocks excessivos.
- Verificar testes acoplados à implementação.
- Verificar dependência de tempo real.
- Verificar aleatoriedade não controlada.
- Verificar timers não controlados.
- Verificar chamadas externas reais.
- Verificar dados compartilhados entre testes.

## Regressões

- Verificar testes removidos.
- Verificar testes ignorados.
- Verificar assertions enfraquecidas.
- Verificar testes alterados apenas para fazer passar.
- Verificar se teste de regressão falharia antes do fix.

Aplicar também os critérios da skill
`react-testing` quando necessário.
