# Acessibilidade E UI

## HTML Semântico

- Verificar uso correto de button, label, input e link.
- Verificar elementos clicáveis sem semântica.
- Verificar labels associados aos campos.
- Verificar headings quando relevantes.
- Verificar uso inadequado de div como controle interativo.

## Teclado E Foco

- Verificar navegação por teclado.
- Verificar foco após abertura de modal.
- Verificar retorno de foco após fechamento.
- Verificar focus trap quando necessário.
- Verificar componentes inacessíveis sem mouse.

## ARIA

- Verificar ARIA incorreto ou desnecessário.
- Verificar accessible name.
- Verificar `aria-expanded`.
- Verificar `aria-invalid`.
- Verificar mensagens dinâmicas relevantes.

## Estados De Interface

- Verificar loading perceptível.
- Verificar error state.
- Verificar empty state.
- Verificar controles desabilitados.
- Verificar feedback após ações.
