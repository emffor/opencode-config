# Dependências, Configuração E Compatibilidade

## Dependências

- Verificar mudanças em `package.json`.
- Verificar mudanças no lockfile.
- Confirmar necessidade de nova dependência.
- Verificar dependências duplicadas.
- Verificar atualização fora do escopo.
- Verificar pacote abandonado ou incompatível.
- Verificar impacto no bundle.

## Configuração

- Verificar variáveis de ambiente novas.
- Verificar defaults seguros.
- Verificar secrets em arquivos versionados.
- Verificar mudanças de build.
- Verificar aliases e paths.
- Verificar configuração de TypeScript.
- Verificar configuração de lint e testes.

## Compatibilidade

- Verificar versão do React.
- Verificar versão do Node.
- Verificar versão do TypeScript.
- Verificar package manager.
- Verificar APIs indisponíveis na versão atual.
- Verificar compatibilidade com browsers suportados.
- Verificar breaking changes.
- Não aprovar modernização fora do escopo.
