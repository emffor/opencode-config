# Forms E Validação

## Forms

- Verificar campos controlled e uncontrolled.
- Verificar estado inicial dos campos.
- Verificar reset incorreto após submit.
- Verificar double submit.
- Verificar botão não desabilitado quando necessário.
- Verificar valores stale durante submit.
- Verificar campos condicionais.

## Validação

- Verificar campos obrigatórios.
- Verificar validações condicionais.
- Verificar arrays, datas, números e enums.
- Verificar validação de arquivos.
- Verificar MIME type, extensão e tamanho.
- Verificar mensagens de erro inconsistentes.
- Verificar erros retornados pelo backend.
- Verificar uso de valores não validados.
- Verificar validação apenas no frontend para regras de segurança.
- Verificar divergência entre frontend e backend.

## Submit

- Verificar tratamento de loading.
- Verificar tratamento de sucesso.
- Verificar tratamento de erro.
- Verificar retry acidental.
- Verificar chamadas duplicadas.
- Verificar navegação antes da operação concluir.
